# 0. 验证原则

- **数据驱动**：所有验证必须基于实际数据结果，禁止"已验证"等无证据声明
- **三选一铁律**：每个 Task 至少展示 行数核验 / 抽样对比 / 对账 SQL 三选一的实际证据
- **对比验证**：核心指标必须与已知正确值（业务库直查 / 旧版本 / Excel 基准）做交叉对比
- **边界测试**：必须测试空值、零值、负值、超大值、跨年/跨月、迟到数据等边界条件
- **回刷可重入**：所有写入逻辑必须保证幂等（INSERT OVERWRITE 或 MERGE 而非 INSERT）
