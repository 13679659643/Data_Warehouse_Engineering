# 安全红线

## 1. 数据安全

- ❌ 禁止在 SQL / ETL 脚本 / 调度配置中硬编码数据库密码、API Key、连接字符串中的凭据
- ❌ 禁止在 ADS / 视图中直接展示用户身份证号、手机号、银行卡号、密码等 PII 数据（必须脱敏或哈希）
- ❌ 禁止将包含敏感数据的 SQL 结果通过非安全渠道（IM / 邮件附件 / 截图）传输
- ❌ 禁止在测试环境使用真实生产数据（应使用脱敏样本）
- ❌ 禁止在公共 Git 仓库提交带有密钥 / 内部数据样本的文件

## 2. 字段级脱敏标准

| 字段类型 | 脱敏方式 | 示例 |
|---------|---------|------|
| 手机号 | 中间 4 位掩码 | 138****1234 |
| 身份证 | 出生日期段掩码 | 110101********1234 |
| 邮箱 | 用户名前 3 位 + ***  | abc***@example.com |
| 银行卡 | 仅末 4 位 | ************1234 |
| 姓名（中文） | 仅姓 + * | 张** |
| 地址 | 区县级以下掩码 | 北京市朝阳区**** |
| 身份证号哈希 | SHA-256 + salt | 用于去重而不暴露明文 |

实现示例：
```sql
-- 手机号脱敏
CONCAT(SUBSTR(phone, 1, 3), '****', SUBSTR(phone, 8, 4)) AS phone_masked

-- 身份证哈希（用于跨表关联但不暴露明文）
SHA2(CONCAT(id_card, '${salt}'), 256) AS id_card_hash
```

## 3. 行级权限（RLS）

- ⚠️ 涉及多租户 / 多组织 / 多业务线的数仓表，必须配置行级权限
- ⚠️ RLS 规则必须在 spec 中明确定义，并经人工审查后方可实施
- ⚠️ RLS 规则变更必须验证：
  - 测试每个角色 / 用户只能看到授权数据
  - 测试无角色用户被正确拒绝
  - 测试管理员 / 超级权限的访问范围
- ⚠️ 严禁使用代码绕过权限校验（如直接读底层文件）

## 4. 数据分级与访问控制

### 分级
| 级别 | 含义 | 示例 | 访问限制 |
|------|------|------|---------|
| L1 公开 | 可对外公开 | 公开统计报告 | 无 |
| L2 内部 | 公司内部使用 | 业务运营数据 | 公司员工 |
| L3 机密 | 部分人员访问 | 财务、薪酬 | 授权岗位 |
| L4 高度机密 | 严格管控 | 个人 PII / 客户隐私 | 必须工单 + 审计 |

### 控制
- L4 数据访问必须留痕（审计日志保留 ≥ 6 个月）
- L3+ 数据导出必须二次审批
- 跨级别合并表必须按最高级别管控

## 5. 上线与发布安全

- ⚠️ 生产 SQL 上线必须经过代码评审（PR Review）
- ⚠️ 涉及 PII / 财务的表上线必须经过数据负责人 + 安全负责人双签
- ⚠️ 任何 DDL 变更（删表 / 删字段 / 改主键）必须有回滚预案
- ⚠️ 数据网关 / 服务账号必须使用统一密钥管理（KMS / Vault），不得使用个人账号
- ⚠️ 临时探索查询禁止落地到生产库

## 6. 数据回刷安全

- ⚠️ 历史回刷必须明确范围、影响下游、回退方案
- ⚠️ 涉及对外指标的回刷需要发布"数据修订公告"
- ⚠️ 回刷必须在低峰期执行，避免影响日常作业

## 7. 业务安全

- ⚠️ 涉及财务 / 营收 / 上市口径的指标必须在 spec 中标注精度、四舍五入规则、对外披露口径
- ⚠️ 涉及预测 / 预算的指标必须明确数据时效性与可靠性，禁止与历史实绩混淆展示
- ⚠️ 对外发布的报表必须经过数据准确性审查与法务合规审查（如适用）

## 8. 跨境合规

- ⚠️ 涉及跨境数据传输（如跨境业务）必须符合 GDPR / PIPL 等法规
- ⚠️ 出境数据必须做必要的去标识化处理
- ⚠️ 跨境数据分类必须有数据出境清单 + 审批记录

## 9. 安全审计

- ⚠️ 所有 L3+ 数据的查询必须留痕（query log + user + table）
- ⚠️ 异常访问行为（如非工作时间高频访问 PII 表）必须告警
- ⚠️ 离职员工必须在离职日 24 小时内回收数仓权限

## 10. 应急响应

- 发现数据泄露 → 立即冻结相关账号 / 视图 → 通知安全团队 + 数据负责人 → 启动 RCA
- 发现错误数据流出 → 立即下线对外接口 → 评估影响范围 → 公告 + 修复 + 回放
- 发现 SQL 注入 / 漏洞 → 立即修补 + 全量审计相关入口
