# 任务拆分 — 变更名称

> 拆分顺序：数据源接入 → ODS 落地 → DIM 维度建设 → DWD 明细加工 → DWS 汇总 → ADS 应用层 → 调度配置 → 数据质量 → 权限发布
> 每个任务 = 可独立验证的原子变更
> 每个任务必须精确到 库.表.字段 / 作业名 / 调度依赖

## 前置条件

- [ ] 数据源连接已确认可用，账号/网络已开通
- [ ] 项目上下文（rules/project-context.md）已更新
- [ ] 涉及的上游表已就绪
- [ ] 调度系统资源队列已确认
- [ ] （其他依赖/配置前提）

## Task 1: 任务名

- **目标**: 一句话描述
- **分层**: ODS / DWD / DWS / ADS / DIM
- **涉及变更**:
  - DDL: 库.表 — 新建/修改字段/分区
  - SQL: 脚本路径 — 新增/修改逻辑
  - ETL: 同步任务名 — 配置变更
  - 调度: 作业名 — 依赖、周期、SLA 调整
- **关键 DDL**（如适用）:
  ```sql
  CREATE TABLE IF NOT EXISTS dwh_dwd.dwd_xxx_di (
      ...
  ) PARTITIONED BY (dt STRING COMMENT 'YYYYMMDD');
  ```
- **关键 SQL**（如适用）:
  ```sql
  -- ============================
  -- 用途：xxx
  -- 依赖：xxx
  -- 产出：xxx
  -- ============================
  INSERT OVERWRITE TABLE dwh_dwd.dwd_xxx_di PARTITION (dt='${bizdate}')
  SELECT ...
  FROM ...;
  ```
- **依赖**: 无 / Task N
- **验收标准**: 怎样算完成（具体数值或可观测行为，如：行数 = xxx，关键指标 = xxx）
- **验证方法**:
  - [ ] 行数核验：`SELECT COUNT(*) FROM ... WHERE dt='${bizdate}'`
  - [ ] 关键字段非空率达标
  - [ ] 主键唯一性校验通过
  - [ ] 与基准来源对账差异 < x%
  - [ ] 单作业耗时 < x 分钟
- **回刷计划**（如涉及）：
  - 范围：dt=YYYYMMDD ~ dt=YYYYMMDD
  - 分批策略：每批 N 个分区，间隔 M 分钟
  - 失败处理：单分区失败 → 重试 3 次 → 告警人工介入
