# 线性递推闭式解版本：非递归实现 plan_post / plan_post_assist

> 本文档是基于《闭式解方案-非递归实现plan_post_assist.md》推导的完整实现，
> 将原 WITH RECURSIVE 递归 CTE 替换为窗口函数（EXP+SUM+LN），解决 StarRocks 不支持递归、
> 手动展开 180 段 UNION ALL 性能爆炸的问题。
>
> ## 核心数学原理
>
> 定义 R(N) = Q - cum_plan_post_assist(N)（第N天开始时的剩余待分配量），递推：
> - 有实际销量：R(N+1) = R(N) - actual_qty(N)，即 k=1, d=actual_qty
> - 无实际销量：R(N+1) = R(N) * (1 - ratio/(181-N))，即 k=1-ratio/(181-N), d=0
>
> 闭式解：**R(N) = P(N) * [Q - S(N)]**
> - P(N) = Π(j=1 to N-1) k(j) = 前(N-1)个k的连乘，P(1)=1
> - S(N) = Σ(i=1 to N-1) d(i)/P(i+1) = 前(N-1)个 d(i)/P(i+1) 的累加，S(1)=0
>
> P 用 `EXP(SUM(LN(k)))` 实现，S 用 `SUM(d/P_i1)` 实现，纯窗口函数无需递归。
>
> ## 适用范围
> - 情况1/2（'<上架时间' / '>=上架时间,<=180天'）：1~180天用闭式解，超周期段为0
> - 情况3（'>180天'）：1~180天直接用 (Q-cum_actual)*ratio/(181-N)（不依赖 cum_is_not_0_sum）
>                    超周期段三者都=(Q-cum_actual)*1

## feishu\_dws\.dws\_sku\_sales\_plan\_180d\_d

```SQL
-- ============================================================
-- ETL: feishu_dws.dws_sku_sales_plan_180d_d
-- 粒度：style_no_size + sale_date
-- 日期补齐：每个SKU从 shelf_date 到 全局最晚shelf_date+180天
-- 渠道：韦德4核心渠道
-- 口径：4.1~4.6节 + 三期口径第3/4节
-- 设计要点：
--   1. 复用 dws_sku_product_info_d 已聚合好的商品维度字段
--   2. 修复 cum_actual 稀疏断档Bug：先展开日历 LEFT JOIN 销量，再在连续数据上用窗口函数
--   3. 可售周期：1~180天用滚动近30天日销（不含当天），超周期用当前时间近30天日销
--   4. 日期序列：GENERATE_SERIES(0, DATEDIFF) + DATE_ADD
--   5. ★闭式解方案：用 EXP(SUM(LN(k))) + SUM(d/P_i1) 窗口函数替代递归CTE
--      数学原理: R(N)=P(N)*[Q-S(N)],其中 P=累计乘积,S=加权累计求和
-- ============================================================
TRUNCATE TABLE feishu_dws.dws_sku_sales_plan_180d_d;

INSERT INTO feishu_dws.dws_sku_sales_plan_180d_d (
    style_no_size, sale_date, lifecycle_day, sale_date_label,
    sales_cycle_label, ratio, sales_plan_tag, brand, style_no, size, shelf_date,
    order_qty, plan_pre, plan_post, plan_post_assist, actual_qty, actual_amt,
    cum_actual, cum_actual_amt, cum_plan_qty, cum_plan_post_assist, cum_plan_amt, should_achieve_ratio, achievement_rate,
    inventory_sku, available_inventory, sellable_days,
    sync_time, insert_date, update_date
)
WITH
-- ============================================================
-- 1. 销售明细按 style_no_size + sales_date 聚合（核心4渠道）
--    稀疏表：只有有销量的日期才有记录
-- ============================================================
sales_daily AS (
    SELECT
        CONCAT_WS('-', s.style_no, s.size)                 AS style_no_size,
        s.sales_date                                       AS sales_date,
        COALESCE(SUM(s.qty), 0)                            AS daily_qty,
        COALESCE(SUM(s.amt), 0)                            AS daily_amt
    FROM feishu_dwd.dwd_feishu_sales_all_d s
    WHERE s.brand = '韦德'
      AND s.channel_code IN ('wd', 'japan', 'spanish', 'germany')
    GROUP BY CONCAT_WS('-', s.style_no, s.size), s.sales_date
),
-- ============================================================
-- 2. 当前时间的30天平均日销辅助（口径3.12节），用于超周期可售周期
--    直接从 dws_sku_product_info_d 取 daily_avg_qty_30d 更简洁
-- ============================================================
current_30d_avg AS (
    SELECT
        style_no_size,
        sellable_days AS current_sellable_days,
        daily_avg_qty_30d AS current_daily_avg_30d
    FROM feishu_dws.dws_sku_product_info_d
),
-- ============================================================
-- 3. 全局最晚 shelf_date（用于确定补齐结束日 = 最晚shelf_date + 180天）
-- ============================================================
global_max_shelf AS (
    SELECT MAX(shelf_date) AS max_shelf_date
    FROM feishu_dws.dws_sku_product_info_d
),
-- ============================================================
-- 4. 日期补齐：每个 SKU 从 shelf_date 到 全局最晚shelf_date+180天
--    新增取 current_lifecycle_day(SKU维度当前时间常量),用于情况2区分已过去日/未来日
-- ============================================================
sku_calendar AS (
    SELECT
        p.style_no_size                                       AS style_no_size,
        p.brand                                               AS brand,
        p.style_no                                            AS style_no,
        p.size                                                AS size,
        p.shelf_date                                          AS shelf_date,
        p.inventory_sku                                       AS inventory_sku,
        p.available_inventory                                 AS available_inventory,
        p.order_qty                                           AS order_qty,
        p.sync_time                                           AS sync_time,
        p.sales_plan_tag                                      AS sales_plan_tag,
        -- 三期口径第2节: current_lifecycle_day = 当日已上架天数(SKU维度当前时间常量,来自dws_sku_product_info_d.lifecycle_day)
        p.lifecycle_day                                       AS current_lifecycle_day,
        gs.day_offset + 1                                     AS lifecycle_day,
        DATE_ADD(p.shelf_date, INTERVAL gs.day_offset DAY)    AS sale_date
    FROM feishu_dws.dws_sku_product_info_d p
    CROSS JOIN global_max_shelf gms
    CROSS JOIN GENERATE_SERIES(
        0,
        DATEDIFF(DATE_ADD(gms.max_shelf_date, INTERVAL 180 DAY), p.shelf_date)
    ) AS gs(day_offset)
),
-- ============================================================
-- 5. 关联日销：保证每个 SKU 每天都有一条记录，没销量的日期补0
-- ============================================================
sku_with_sales AS (
    SELECT
        sc.*,
        COALESCE(sd.daily_qty, 0) AS actual_qty,
        COALESCE(sd.daily_amt, 0) AS actual_amt
    FROM sku_calendar sc
    LEFT JOIN sales_daily sd
        ON sc.style_no_size = sd.style_no_size
       AND sc.sale_date = sd.sales_date
),
-- ============================================================
-- 6. 在连续日历数据上计算累计销量和滚动近30天日销（关键修复）
--    - cum_actual: 截至N-1天的累计销量
--    - rolling_30d_qty: 滚动近30天销量（不含当天）
-- ============================================================
sales_cum AS (
    SELECT
        style_no_size,
        sale_date,
        lifecycle_day,
        current_lifecycle_day,
        actual_qty,
        actual_amt,
        brand,
        style_no,
        size,
        shelf_date,
        order_qty,
        inventory_sku,
        available_inventory,
        sync_time,
        sales_plan_tag,
        -- 累计实际销量 = 截至N-1天（不含当天N）
        SUM(actual_qty) OVER (PARTITION BY style_no_size ORDER BY sale_date
                              ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) AS cum_actual,
        SUM(actual_amt) OVER (PARTITION BY style_no_size ORDER BY sale_date
                              ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) AS cum_actual_amt,
        -- 滚动近30天销量（不含当天）
        SUM(actual_qty) OVER (PARTITION BY style_no_size ORDER BY sale_date
                              ROWS BETWEEN 30 PRECEDING AND 1 PRECEDING) AS rolling_30d_qty
    FROM sku_with_sales
),
-- ============================================================
-- 6.1 ★闭式解: 计算递推系数 k(N) 和常数项 d(N)
--     线性递推 R(N+1) = k(N)*R(N) - d(N)
--     情况1(<上架时间): 全部为未来日 -> k=1-ratio/(181-N), d=0
--     情况2(>=上架时间,<=180天) 按时间分两段:
--       已过去日(lifecycle_day < current_lifecycle_day): k=1, d=actual_qty(有就有,没有为0)
--       未来日  (lifecycle_day >= current_lifecycle_day): k=1-ratio/(181-N), d=0
--     情况3(>180天) 1~180天: 不依赖 cum_is_not_0_sum,k/d 不参与计算(置1/0)
--     超周期段/其他场景: k=1, d=0
-- ============================================================
closed_form_base AS (
    SELECT
        sc.*,
        -- ratio: 三期口径第4.2节 阶段系数
        CASE
            WHEN sc.lifecycle_day BETWEEN 1 AND 30    THEN CAST(0.8 AS DECIMAL(18,6))
            WHEN sc.lifecycle_day BETWEEN 31 AND 120  THEN CAST(1.1 AS DECIMAL(18,6))
            WHEN sc.lifecycle_day BETWEEN 121 AND 180 THEN CAST(1.0 AS DECIMAL(18,6))
            ELSE NULL
        END AS ratio,
        -- k(N): 递推系数
        --   情况1(全部未来日) / 情况2未来日(lifecycle_day >= current_lc_day) -> k=1-ratio/(181-N)
        --   情况2已过去日(lifecycle_day < current_lc_day) -> k=1 (直接减actual_qty)
        --   超周期/情况3 -> k=1 (不参与闭式解,置1避免影响累计乘积)
        CASE
            WHEN sc.lifecycle_day BETWEEN 1 AND 180
                 AND sc.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天')
                 AND (
                     -- 情况1: 全部为未来日(current_lc_day<=0 表示尚未上架)
                     sc.sales_plan_tag = '<上架时间'
                     OR
                     -- 情况2未来日: lifecycle_day >= current_lifecycle_day
                     sc.lifecycle_day >= COALESCE(sc.current_lifecycle_day, 0)
                 )
            THEN CAST(1 AS DECIMAL(18,6))
                 - CAST(CASE
                            WHEN sc.lifecycle_day BETWEEN 1 AND 30    THEN CAST(0.8 AS DECIMAL(18,6))
                            WHEN sc.lifecycle_day BETWEEN 31 AND 120  THEN CAST(1.1 AS DECIMAL(18,6))
                            WHEN sc.lifecycle_day BETWEEN 121 AND 180 THEN CAST(1.0 AS DECIMAL(18,6))
                        END AS DECIMAL(18,6))
                 / NULLIF(CAST(181 - sc.lifecycle_day AS DECIMAL(18,6)), 0)
            ELSE CAST(1 AS DECIMAL(18,6))
        END AS k,
        -- d(N): 递推常数项
        --   情况1(全部未来日) / 情况2未来日 -> d=0
        --   情况2已过去日(lifecycle_day < current_lc_day) -> d=actual_qty(有就有,没有为0)
        --   超周期/情况3 -> d=0
        CASE
            WHEN sc.lifecycle_day BETWEEN 1 AND 180
                 AND sc.sales_plan_tag = '>=上架时间,<=180天'
                 AND sc.lifecycle_day < COALESCE(sc.current_lifecycle_day, 0)
            THEN CAST(COALESCE(sc.actual_qty, 0) AS DECIMAL(18,6))
            ELSE CAST(0 AS DECIMAL(18,6))
        END AS d
    FROM sales_cum sc
),
-- ============================================================
-- 6.2 ★闭式解: 计算累计乘积 P(N) 和 P(i+1)
--     P(N)   = Π(j=1 to N-1) k(j)  → 截至 N-1 的累计乘积(不含当天), P(1)=1
--     P(i+1) = Π(j=1 to i) k(j)    → 截至 i 的累计乘积(含当天), 用于算 d(i)/P(i+1)
--     实现: EXP(SUM(LN(k))) (因为 LN(a*b)=LN(a)+LN(b), a*b=EXP(LN(a)+LN(b)))
--     边界处理:
--       - k>0 才取 LN(k), k<=0 用 NULL 跳过(避免 LN(0) 报错)
--       - 第1行 P(N) 窗口返回 NULL, 用 COALESCE(...,1) 兜底为1
--       - 第180天无实际销量时 k=1-1/1=0, P(i+1)=0, 需在后续 d/P_i1 中用 NULLIF 保护
-- ============================================================
closed_form_P AS (
    SELECT
        b.*,
        -- P(N) = 截至 N-1 的累计乘积(不含当天), P(1)=1
        COALESCE(
            EXP(SUM(CASE WHEN b.k > 0 THEN LN(b.k) ELSE NULL END)
                OVER (PARTITION BY b.style_no_size ORDER BY b.sale_date
                      ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)),
            CAST(1 AS DECIMAL(18,6))
        ) AS P_N,
        -- P(i+1) = 截至 i 的累计乘积(含当天), 用于算 d(i)/P(i+1)
        -- 注: k=0 时 P_i1=0, 后续 d/P_i1 用 NULLIF 保护
        EXP(SUM(CASE WHEN b.k > 0 THEN LN(b.k) ELSE NULL END)
            OVER (PARTITION BY b.style_no_size ORDER BY b.sale_date
                  ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)) AS P_i1
    FROM closed_form_base b
),
-- ============================================================
-- 6.3 ★闭式解: 计算加权累计和 S(N)
--     S(N) = Σ(i=1 to N-1) d(i)/P(i+1)  → 截至 N-1 的累计求和(不含当天), S(1)=0
--     实现: SUM(d / NULLIF(P_i1, 0)) 窗口函数
--     边界处理: P_i1=0 时(NULLIF 返回 NULL), d/P_i1=NULL, SUM 跳过 NULL
-- ============================================================
closed_form_S AS (
    SELECT
        p.*,
        -- S(N) = Σ(i=1 to N-1) d(i)/P(i+1) 累计求和(不含当天)
        COALESCE(
            SUM(p.d / NULLIF(p.P_i1, 0))
            OVER (PARTITION BY p.style_no_size ORDER BY p.sale_date
                  ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING),
            CAST(0 AS DECIMAL(18,6))
        ) AS S_N
    FROM closed_form_P p
),
-- ============================================================
-- 6.4 ★闭式解: 计算最终字段 plan_pre / plan_post / plan_post_assist
--     闭式解公式:
--       R(N) = P(N) * [Q - S(N)]   ← 剩余待分配量
--       情况1/2 1~180天:
--         plan_post = R(N) * ratio / (181-N)
--         plan_pre  = R(N) * ratio
--         plan_post_assist = CASE WHEN actual_qty>0 THEN actual_qty ELSE plan_post END
--       情况3 1~180天:
--         plan_pre  = (Q - cum_actual) * ratio
--         plan_post = (Q - cum_actual) * ratio / (181-N)
--         plan_post_assist: 1~179天=actual_qty, 第180天=Q-cum_actual(N)
--       超周期段(三者):
--         情况1/2: 全为0
--         情况3:   全为 (Q - cum_actual) * 1
--     特殊处理: 情况1/2 第180天无实际销量时 k=0,P_i1=0,R(180)=P(180)*(Q-S(180))
--              此时 plan_post=R(180)*ratio/1=R(180),数学上正确
-- ============================================================
plan_calc AS (
    SELECT
        cs.*,
        -- 中间量: R(N) = P(N) * (Q - S(N))
        -- 仅情况1/2在1~180天使用闭式解;情况3用 (Q-cum_actual)
        CASE
            WHEN cs.lifecycle_day BETWEEN 1 AND 180
                 AND cs.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天')
            THEN cs.P_N * (CAST(cs.order_qty AS DECIMAL(18,6)) - cs.S_N)
            ELSE NULL
        END AS R_N,

        -- 三期口径第4节: plan_pre 按 sales_plan_tag 分3种逻辑
        CASE
            -- 超周期段: 情况3 =(Q-cum_actual)*1, 情况1/2 = 0
            WHEN cs.lifecycle_day > 180 THEN
                CASE WHEN cs.sales_plan_tag = '>180天' THEN
                    (CAST(cs.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                    * CAST(1.0 AS DECIMAL(18,6))
                ELSE CAST(0 AS DECIMAL(18,6))
                END
            -- 情况1/2 1~180天: plan_pre = R(N) * ratio (闭式解)
            WHEN cs.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天') THEN
                cs.P_N * (CAST(cs.order_qty AS DECIMAL(18,6)) - cs.S_N)
                * cs.ratio
            -- 情况3 1~180天: plan_pre = (Q - cum_actual) * ratio
            WHEN cs.sales_plan_tag = '>180天' THEN
                (CAST(cs.order_qty AS DECIMAL(18,6))
                 - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                * cs.ratio
            ELSE NULL
        END AS plan_pre_final,

        -- 三期口径第4节: plan_post 按 sales_plan_tag 分3种逻辑
        CASE
            -- 超周期段: 情况3 =(Q-cum_actual)*1, 情况1/2 = 0
            WHEN cs.lifecycle_day > 180 THEN
                CASE WHEN cs.sales_plan_tag = '>180天' THEN
                    (CAST(cs.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                    * CAST(1.0 AS DECIMAL(18,6))
                ELSE CAST(0 AS DECIMAL(18,6))
                END
            -- 情况1/2 1~180天: plan_post = R(N) * ratio / (181-N) (闭式解)
            WHEN cs.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天') THEN
                cs.P_N * (CAST(cs.order_qty AS DECIMAL(18,6)) - cs.S_N)
                * cs.ratio
                / NULLIF(CAST(181 - cs.lifecycle_day AS DECIMAL(18,6)), 0)
            -- 情况3 1~180天: plan_post = (Q - cum_actual) * ratio / (181-N)
            WHEN cs.sales_plan_tag = '>180天' THEN
                (CAST(cs.order_qty AS DECIMAL(18,6))
                 - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                * cs.ratio
                / NULLIF(CAST(181 - cs.lifecycle_day AS DECIMAL(18,6)), 0)
            ELSE NULL
        END AS plan_post_final
    FROM closed_form_S cs
),
-- ============================================================
-- 6.5 ★计算 plan_post_assist / cum_plan_post_assist / cum_plan_qty
--     plan_post_assist 按 sales_plan_tag 分3种逻辑:
--       情况1(<上架时间): 全部未来日 -> 始终=plan_post
--       情况2(>=上架时间,<=180天) 按时间分两段:
--         已过去日(lifecycle_day < current_lc_day): =actual_qty(有就有,没有为0)
--         未来日  (lifecycle_day >= current_lc_day): =plan_post
--       情况3(>180天): 1~179天取actual_qty, 第180天取Q-cum_actual(N), 超周期取(Q-cum_actual)*1
--     cum_plan_post_assist = 截至N-1天的 SUM(plan_post_assist)
--       1~180天: 滚动累计(不含当天N)
--       超周期段: 保持第180天值
--     cum_plan_qty = 截至N-1天的 SUM(plan_post_final)
--       1~180天: 滚动累计(不含当天N)
--       超周期段: 保持第180天值(取所有1~180天plan_post的总和)
-- ============================================================
plan_with_assist AS (
    SELECT
        pc.*,
        -- 三期口径第3节: plan_post_assist
        CASE
            -- 超周期段: 情况3 =(Q-cum_actual)*1, 情况1/2 = 0
            WHEN pc.lifecycle_day > 180 THEN
                CASE WHEN pc.sales_plan_tag = '>180天' THEN
                    (CAST(pc.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(pc.cum_actual, 0) AS DECIMAL(18,6)))
                    * CAST(1.0 AS DECIMAL(18,6))
                ELSE CAST(0 AS DECIMAL(18,6))
                END
            -- 情况2 1~180天 按时间分两段:
            --   已过去日(lifecycle_day < current_lc_day): =actual_qty(有就有,没有为0)
            --   未来日  (lifecycle_day >= current_lc_day): =plan_post
            WHEN pc.sales_plan_tag = '>=上架时间,<=180天' THEN
                CASE WHEN pc.lifecycle_day < COALESCE(pc.current_lifecycle_day, 0)
                     THEN CAST(COALESCE(pc.actual_qty, 0) AS DECIMAL(18,6))
                     ELSE pc.plan_post_final
                END
            -- 情况1 1~180天: 全部未来日 -> 始终=plan_post
            WHEN pc.sales_plan_tag = '<上架时间' THEN
                pc.plan_post_final
            -- 情况3 1~180天: 第180天取 Q-cum_actual(N), 1~179天取 actual_qty
            WHEN pc.sales_plan_tag = '>180天' THEN
                CASE WHEN pc.lifecycle_day = 180 THEN
                    (CAST(pc.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(pc.cum_actual, 0) AS DECIMAL(18,6)))
                ELSE
                    CAST(COALESCE(pc.actual_qty, 0) AS DECIMAL(18,6))
                END
            ELSE NULL
        END AS plan_post_assist,
        -- cum_plan_qty: 累计计划销量(截至N-1天的SUM(plan_post_final))
        -- 1~180天: 滚动累计(不含当天N), 用 ORDER BY + ROWS 1 PRECEDING
        -- 超周期段: 保持第180天值 = 该SKU所有1~180天plan_post的总和
        --          用不带 ORDER BY 的聚合窗口函数(默认整个分区,每行返回同一值)
        --          注: StarRocks 要求 ROWS BETWEEN 必须搭配 ORDER BY,
        --              所以超周期段不能写 ROWS BETWEEN UNBOUNDED ... AND UNBOUNDED ...
        CASE WHEN pc.lifecycle_day BETWEEN 1 AND 180 THEN
            SUM(CASE WHEN pc.lifecycle_day BETWEEN 1 AND 180
                     THEN pc.plan_post_final ELSE 0 END
               ) OVER (PARTITION BY pc.style_no_size ORDER BY pc.sale_date
                       ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)
        ELSE
            SUM(CASE WHEN pc.lifecycle_day BETWEEN 1 AND 180
                     THEN pc.plan_post_final ELSE 0 END
               ) OVER (PARTITION BY pc.style_no_size)
        END AS cum_plan_qty
    FROM plan_calc pc
),
-- ============================================================
-- 6.6 ★计算 cum_plan_post_assist = 截至N-1天的 SUM(plan_post_assist)
--     逻辑同 cum_plan_qty,只是把 plan_post_final 换成 plan_post_assist
--     1~180天: 滚动累计(不含当天N)
--     超周期段: 保持第180天值(取所有1~180天plan_post_assist的总和)
-- ============================================================
plan_with_cum_assist AS (
    SELECT
        pa.*,
        CASE WHEN pa.lifecycle_day BETWEEN 1 AND 180 THEN
            SUM(CASE WHEN pa.lifecycle_day BETWEEN 1 AND 180
                     THEN pa.plan_post_assist ELSE 0 END
               ) OVER (PARTITION BY pa.style_no_size ORDER BY pa.sale_date
                       ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)
        ELSE
            SUM(CASE WHEN pa.lifecycle_day BETWEEN 1 AND 180
                     THEN pa.plan_post_assist ELSE 0 END
               ) OVER (PARTITION BY pa.style_no_size)
        END AS cum_plan_post_assist
    FROM plan_with_assist pa
)
SELECT
    sc.style_no_size                                       AS style_no_size,
    sc.sale_date                                           AS sale_date,
    sc.lifecycle_day                                       AS lifecycle_day,
    -- 口径4.1节：sale_date_label
    CASE WHEN sc.lifecycle_day BETWEEN 1 AND 180
         THEN CAST(sc.lifecycle_day AS VARCHAR)
         ELSE '超周期'
    END                                                    AS sale_date_label,
    -- 口径4.2节：销售周期标签
    CASE
        WHEN sc.lifecycle_day BETWEEN 1 AND 30    THEN '新品期'
        WHEN sc.lifecycle_day BETWEEN 31 AND 120  THEN '热销期'
        WHEN sc.lifecycle_day BETWEEN 121 AND 180 THEN '清货期'
        ELSE '超周期'
    END                                                    AS sales_cycle_label,
    -- 口径4.2节：ratio
    sc.ratio                                               AS ratio,
    -- 三期口径第2节：销售计划标签
    sc.sales_plan_tag                                      AS sales_plan_tag,
    sc.brand                                               AS brand,
    sc.style_no                                            AS style_no,
    sc.size                                                AS size,
    sc.shelf_date                                          AS shelf_date,
    sc.order_qty                                           AS order_qty,
    -- 三期口径第4节：plan_pre
    sc.plan_pre_final                                      AS plan_pre,
    -- 三期口径第4节：plan_post
    sc.plan_post_final                                     AS plan_post,
    -- 三期口径第3节：plan_post_assist
    sc.plan_post_assist                                    AS plan_post_assist,
    -- 口径4.5节：实际销售
    sc.actual_qty                                          AS actual_qty,
    sc.actual_amt                                          AS actual_amt,
    -- 累计实际销量 = 截至N-1天的 SUM(qty)
    COALESCE(sc.cum_actual, 0)                             AS cum_actual,
    COALESCE(sc.cum_actual_amt, 0)                         AS cum_actual_amt,
    -- 累计计划销量 = 截至N-1天的 SUM(plan_post_final)
    sc.cum_plan_qty                                        AS cum_plan_qty,
    -- 累计 plan_post_assist = 截至N-1天的 SUM(plan_post_assist)
    sc.cum_plan_post_assist                                AS cum_plan_post_assist,
    -- 累计计划金额 = 占位0（后续补全）
    CAST(0 AS DECIMAL(18,6))                               AS cum_plan_amt,
    -- 应达成比例 = cum_plan_qty / order_qty
    CAST(sc.cum_plan_qty AS DECIMAL(18,6))
        / NULLIF(CAST(sc.order_qty AS DECIMAL(18,6)), 0)   AS should_achieve_ratio,
    -- 口径4.6节：达成情况 = actual_qty / plan_post
    CASE WHEN sc.lifecycle_day BETWEEN 1 AND 180
         THEN CAST(sc.actual_qty AS DECIMAL(18,6))
              / NULLIF(sc.plan_post_final, 0)
         ELSE NULL
    END                                                    AS achievement_rate,
    sc.inventory_sku                                       AS inventory_sku,
    sc.available_inventory                                 AS available_inventory,
    -- 口径3.11节：可售周期 = 在仓库存 / 30天平均日销
    CASE
        WHEN sc.inventory_sku = 0 THEN NULL
        WHEN sc.lifecycle_day BETWEEN 1 AND 180 THEN
            CASE
                WHEN COALESCE(sc.rolling_30d_qty, 0) = 0 THEN NULL
                WHEN LEAST(sc.lifecycle_day - 1, 30) = 0 THEN NULL
                ELSE CAST(sc.inventory_sku AS DECIMAL(18,6))
                     / (CAST(sc.rolling_30d_qty AS DECIMAL(18,6))
                        / LEAST(sc.lifecycle_day - 1, 30))
            END
        ELSE
            COALESCE(c30.current_sellable_days, 0)
    END                                                    AS sellable_days,
    sc.sync_time                                           AS sync_time,
    CURRENT_TIMESTAMP()                                    AS insert_date,
    CURRENT_TIMESTAMP()                                    AS update_date
FROM plan_with_cum_assist sc
LEFT JOIN current_30d_avg c30    ON sc.style_no_size = c30.style_no_size
ORDER BY sc.style_no_size, sc.sale_date;

-- ============================================================
-- ETL: feishu_dws.dws_skc_sales_plan_180d_d
-- 粒度：style_no + sale_date
-- 日期补齐：每个SKC从 shelf_date 到 全局最晚shelf_date+180天
-- 渠道：韦德4核心渠道
-- 口径：6.1~6.6节 + 三期口径第3/4节
-- 设计要点：
--   1. 复用 dws_skc_product_info_d 已聚合好的商品维度字段
--   2. 修复 cum_actual 稀疏断档Bug
--   3. 可售周期：1~180天用滚动近30天日销，超周期用当前时间近30天日销
--   4. ★闭式解方案: 窗口函数替代递归CTE(同SKU表逻辑,维度改为 style_no)
-- ============================================================
TRUNCATE TABLE feishu_dws.dws_skc_sales_plan_180d_d;

INSERT INTO feishu_dws.dws_skc_sales_plan_180d_d (
    style_no, sale_date, lifecycle_day, sale_date_label,
    sales_cycle_label, ratio, sales_plan_tag, brand, shelf_date,
    order_qty, plan_pre, plan_post, plan_post_assist, actual_qty, actual_amt,
    cum_actual, cum_actual_amt, cum_plan_qty, cum_plan_post_assist, cum_plan_amt, should_achieve_ratio, achievement_rate,
    inventory_sku, available_inventory, sellable_days,
    sync_time, insert_date, update_date
)
WITH
-- ============================================================
-- 1. SKC 销售明细按 style_no + sales_date 聚合（核心4渠道）
-- ============================================================
sales_daily_skc AS (
    SELECT
        s.style_no                                         AS style_no,
        s.sales_date                                       AS sales_date,
        COALESCE(SUM(s.qty), 0)                            AS daily_qty,
        COALESCE(SUM(s.amt), 0)                            AS daily_amt
    FROM feishu_dwd.dwd_feishu_sales_all_d s
    WHERE s.brand = '韦德'
      AND s.channel_code IN ('wd', 'japan', 'spanish', 'germany')
    GROUP BY s.style_no, s.sales_date
),
-- ============================================================
-- 2. 当前时间的30天平均日销辅助（口径5.12节），用于超周期可售周期
-- ============================================================
current_30d_avg_skc AS (
    SELECT
        style_no,
        sellable_days AS current_sellable_days,
        daily_avg_qty_30d AS current_daily_avg_30d
    FROM feishu_dws.dws_skc_product_info_d
),
-- ============================================================
-- 3. 全局最晚 shelf_date
-- ============================================================
global_max_shelf_skc AS (
    SELECT MAX(shelf_date) AS max_shelf_date
    FROM feishu_dws.dws_skc_product_info_d
),
-- ============================================================
-- 4. 日期补齐：每个 SKC 从 shelf_date 到 全局最晚shelf_date+180天
--    新增取 current_lifecycle_day(SKC维度当前时间常量),用于情况2区分已过去日/未来日
-- ============================================================
skc_calendar AS (
    SELECT
        p.style_no                                            AS style_no,
        p.brand                                               AS brand,
        p.shelf_date                                          AS shelf_date,
        p.inventory_sku                                       AS inventory_sku,
        p.available_inventory                                 AS available_inventory,
        p.order_qty                                           AS order_qty,
        p.sync_time                                           AS sync_time,
        p.sales_plan_tag                                      AS sales_plan_tag,
        -- 三期口径第2节: current_lifecycle_day = 当日已上架天数(SKC维度当前时间常量,来自dws_skc_product_info_d.lifecycle_day)
        p.lifecycle_day                                       AS current_lifecycle_day,
        gs.day_offset + 1                                     AS lifecycle_day,
        DATE_ADD(p.shelf_date, INTERVAL gs.day_offset DAY)    AS sale_date
    FROM feishu_dws.dws_skc_product_info_d p
    CROSS JOIN global_max_shelf_skc gms
    CROSS JOIN GENERATE_SERIES(
        0,
        DATEDIFF(DATE_ADD(gms.max_shelf_date, INTERVAL 180 DAY), p.shelf_date)
    ) AS gs(day_offset)
),
-- ============================================================
-- 5. 关联日销：保证每个 SKC 每天都有一条记录，没销量的日期补0
-- ============================================================
skc_with_sales AS (
    SELECT
        sc.*,
        COALESCE(sd.daily_qty, 0) AS actual_qty,
        COALESCE(sd.daily_amt, 0) AS actual_amt
    FROM skc_calendar sc
    LEFT JOIN sales_daily_skc sd
        ON sc.style_no = sd.style_no
       AND sc.sale_date = sd.sales_date
),
-- ============================================================
-- 6. 在连续日历数据上计算累计销量和滚动近30天日销
-- ============================================================
sales_cum_skc AS (
    SELECT
        style_no,
        sale_date,
        lifecycle_day,
        current_lifecycle_day,
        actual_qty,
        actual_amt,
        brand,
        shelf_date,
        order_qty,
        inventory_sku,
        available_inventory,
        sync_time,
        sales_plan_tag,
        -- 累计实际销量 = 截至N-1天
        SUM(actual_qty) OVER (PARTITION BY style_no ORDER BY sale_date
                              ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) AS cum_actual,
        SUM(actual_amt) OVER (PARTITION BY style_no ORDER BY sale_date
                              ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING) AS cum_actual_amt,
        -- 滚动近30天销量（不含当天）
        SUM(actual_qty) OVER (PARTITION BY style_no ORDER BY sale_date
                              ROWS BETWEEN 30 PRECEDING AND 1 PRECEDING) AS rolling_30d_qty
    FROM skc_with_sales
),
-- ============================================================
-- 6.1 ★闭式解: 计算递推系数 k(N) 和常数项 d(N) (同SKU表逻辑,维度改为 style_no)
--     线性递推 R(N+1) = k(N)*R(N) - d(N)
--     情况1(<上架时间): 全部为未来日 -> k=1-ratio/(181-N), d=0
--     情况2(>=上架时间,<=180天) 按时间分两段:
--       已过去日(lifecycle_day < current_lifecycle_day): k=1, d=actual_qty(有就有,没有为0)
--       未来日  (lifecycle_day >= current_lifecycle_day): k=1-ratio/(181-N), d=0
--     情况3(>180天) 1~180天: 不依赖 cum_is_not_0_sum,k/d 不参与计算(置1/0)
--     超周期段/其他场景: k=1, d=0
-- ============================================================
closed_form_base_skc AS (
    SELECT
        sc.*,
        -- ratio: 阶段系数
        CASE
            WHEN sc.lifecycle_day BETWEEN 1 AND 30    THEN CAST(0.8 AS DECIMAL(18,6))
            WHEN sc.lifecycle_day BETWEEN 31 AND 120  THEN CAST(1.1 AS DECIMAL(18,6))
            WHEN sc.lifecycle_day BETWEEN 121 AND 180 THEN CAST(1.0 AS DECIMAL(18,6))
            ELSE NULL
        END AS ratio,
        -- k(N): 递推系数
        --   情况1(全部未来日) / 情况2未来日(lifecycle_day >= current_lc_day) -> k=1-ratio/(181-N)
        --   情况2已过去日(lifecycle_day < current_lc_day) -> k=1 (直接减actual_qty)
        --   超周期/情况3 -> k=1 (不参与闭式解,置1避免影响累计乘积)
        CASE
            WHEN sc.lifecycle_day BETWEEN 1 AND 180
                 AND sc.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天')
                 AND (
                     -- 情况1: 全部为未来日
                     sc.sales_plan_tag = '<上架时间'
                     OR
                     -- 情况2未来日: lifecycle_day >= current_lifecycle_day
                     sc.lifecycle_day >= COALESCE(sc.current_lifecycle_day, 0)
                 )
            THEN CAST(1 AS DECIMAL(18,6))
                 - CAST(CASE
                            WHEN sc.lifecycle_day BETWEEN 1 AND 30    THEN CAST(0.8 AS DECIMAL(18,6))
                            WHEN sc.lifecycle_day BETWEEN 31 AND 120  THEN CAST(1.1 AS DECIMAL(18,6))
                            WHEN sc.lifecycle_day BETWEEN 121 AND 180 THEN CAST(1.0 AS DECIMAL(18,6))
                        END AS DECIMAL(18,6))
                 / NULLIF(CAST(181 - sc.lifecycle_day AS DECIMAL(18,6)), 0)
            ELSE CAST(1 AS DECIMAL(18,6))
        END AS k,
        -- d(N): 递推常数项
        --   情况1(全部未来日) / 情况2未来日 -> d=0
        --   情况2已过去日(lifecycle_day < current_lc_day) -> d=actual_qty(有就有,没有为0)
        --   超周期/情况3 -> d=0
        CASE
            WHEN sc.lifecycle_day BETWEEN 1 AND 180
                 AND sc.sales_plan_tag = '>=上架时间,<=180天'
                 AND sc.lifecycle_day < COALESCE(sc.current_lifecycle_day, 0)
            THEN CAST(COALESCE(sc.actual_qty, 0) AS DECIMAL(18,6))
            ELSE CAST(0 AS DECIMAL(18,6))
        END AS d
    FROM sales_cum_skc sc
),
-- ============================================================
-- 6.2 ★闭式解: 计算累计乘积 P(N) 和 P(i+1)
-- ============================================================
closed_form_P_skc AS (
    SELECT
        b.*,
        -- P(N) = 截至 N-1 的累计乘积(不含当天), P(1)=1
        COALESCE(
            EXP(SUM(CASE WHEN b.k > 0 THEN LN(b.k) ELSE NULL END)
                OVER (PARTITION BY b.style_no ORDER BY b.sale_date
                      ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)),
            CAST(1 AS DECIMAL(18,6))
        ) AS P_N,
        -- P(i+1) = 截至 i 的累计乘积(含当天)
        EXP(SUM(CASE WHEN b.k > 0 THEN LN(b.k) ELSE NULL END)
            OVER (PARTITION BY b.style_no ORDER BY b.sale_date
                  ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)) AS P_i1
    FROM closed_form_base_skc b
),
-- ============================================================
-- 6.3 ★闭式解: 计算加权累计和 S(N)
-- ============================================================
closed_form_S_skc AS (
    SELECT
        p.*,
        -- S(N) = Σ(i=1 to N-1) d(i)/P(i+1) 累计求和(不含当天)
        COALESCE(
            SUM(p.d / NULLIF(p.P_i1, 0))
            OVER (PARTITION BY p.style_no ORDER BY p.sale_date
                  ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING),
            CAST(0 AS DECIMAL(18,6))
        ) AS S_N
    FROM closed_form_P_skc p
),
-- ============================================================
-- 6.4 ★闭式解: 计算 plan_pre / plan_post
-- ============================================================
plan_calc_skc AS (
    SELECT
        cs.*,
        -- 中间量: R(N) = P(N) * (Q - S(N)) (仅情况1/2在1~180天使用)
        CASE
            WHEN cs.lifecycle_day BETWEEN 1 AND 180
                 AND cs.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天')
            THEN cs.P_N * (CAST(cs.order_qty AS DECIMAL(18,6)) - cs.S_N)
            ELSE NULL
        END AS R_N,

        -- plan_pre: 三期口径第4节
        CASE
            -- 超周期段: 情况3 =(Q-cum_actual)*1, 情况1/2 = 0
            WHEN cs.lifecycle_day > 180 THEN
                CASE WHEN cs.sales_plan_tag = '>180天' THEN
                    (CAST(cs.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                    * CAST(1.0 AS DECIMAL(18,6))
                ELSE CAST(0 AS DECIMAL(18,6))
                END
            -- 情况1/2 1~180天: plan_pre = R(N) * ratio (闭式解)
            WHEN cs.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天') THEN
                cs.P_N * (CAST(cs.order_qty AS DECIMAL(18,6)) - cs.S_N)
                * cs.ratio
            -- 情况3 1~180天: plan_pre = (Q - cum_actual) * ratio
            WHEN cs.sales_plan_tag = '>180天' THEN
                (CAST(cs.order_qty AS DECIMAL(18,6))
                 - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                * cs.ratio
            ELSE NULL
        END AS plan_pre_final,

        -- plan_post: 三期口径第4节
        CASE
            -- 超周期段: 情况3 =(Q-cum_actual)*1, 情况1/2 = 0
            WHEN cs.lifecycle_day > 180 THEN
                CASE WHEN cs.sales_plan_tag = '>180天' THEN
                    (CAST(cs.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                    * CAST(1.0 AS DECIMAL(18,6))
                ELSE CAST(0 AS DECIMAL(18,6))
                END
            -- 情况1/2 1~180天: plan_post = R(N) * ratio / (181-N) (闭式解)
            WHEN cs.sales_plan_tag IN ('<上架时间', '>=上架时间,<=180天') THEN
                cs.P_N * (CAST(cs.order_qty AS DECIMAL(18,6)) - cs.S_N)
                * cs.ratio
                / NULLIF(CAST(181 - cs.lifecycle_day AS DECIMAL(18,6)), 0)
            -- 情况3 1~180天: plan_post = (Q - cum_actual) * ratio / (181-N)
            WHEN cs.sales_plan_tag = '>180天' THEN
                (CAST(cs.order_qty AS DECIMAL(18,6))
                 - CAST(COALESCE(cs.cum_actual, 0) AS DECIMAL(18,6)))
                * cs.ratio
                / NULLIF(CAST(181 - cs.lifecycle_day AS DECIMAL(18,6)), 0)
            ELSE NULL
        END AS plan_post_final
    FROM closed_form_S_skc cs
),
-- ============================================================
-- 6.5 ★计算 plan_post_assist / cum_plan_post_assist / cum_plan_qty
--     plan_post_assist 按 sales_plan_tag 分3种逻辑:
--       情况1(<上架时间): 全部未来日 -> 始终=plan_post
--       情况2(>=上架时间,<=180天) 按时间分两段:
--         已过去日(lifecycle_day < current_lc_day): =actual_qty(有就有,没有为0)
--         未来日  (lifecycle_day >= current_lc_day): =plan_post
--       情况3(>180天): 1~179天取actual_qty, 第180天取Q-cum_actual(N), 超周期取(Q-cum_actual)*1
--     cum_plan_post_assist = 截至N-1天的 SUM(plan_post_assist)
--     cum_plan_qty = 截至N-1天的 SUM(plan_post_final)
-- ============================================================
plan_with_assist_skc AS (
    SELECT
        pc.*,
        -- plan_post_assist: 三期口径第3节
        CASE
            -- 超周期段: 情况3 =(Q-cum_actual)*1, 情况1/2 = 0
            WHEN pc.lifecycle_day > 180 THEN
                CASE WHEN pc.sales_plan_tag = '>180天' THEN
                    (CAST(pc.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(pc.cum_actual, 0) AS DECIMAL(18,6)))
                    * CAST(1.0 AS DECIMAL(18,6))
                ELSE CAST(0 AS DECIMAL(18,6))
                END
            -- 情况2 1~180天 按时间分两段:
            --   已过去日(lifecycle_day < current_lc_day): =actual_qty(有就有,没有为0)
            --   未来日  (lifecycle_day >= current_lc_day): =plan_post
            WHEN pc.sales_plan_tag = '>=上架时间,<=180天' THEN
                CASE WHEN pc.lifecycle_day < COALESCE(pc.current_lifecycle_day, 0)
                     THEN CAST(COALESCE(pc.actual_qty, 0) AS DECIMAL(18,6))
                     ELSE pc.plan_post_final
                END
            -- 情况1 1~180天: 全部未来日 -> 始终=plan_post
            WHEN pc.sales_plan_tag = '<上架时间' THEN
                pc.plan_post_final
            -- 情况3 1~180天: 第180天取 Q-cum_actual(N), 1~179天取 actual_qty
            WHEN pc.sales_plan_tag = '>180天' THEN
                CASE WHEN pc.lifecycle_day = 180 THEN
                    (CAST(pc.order_qty AS DECIMAL(18,6))
                     - CAST(COALESCE(pc.cum_actual, 0) AS DECIMAL(18,6)))
                ELSE
                    CAST(COALESCE(pc.actual_qty, 0) AS DECIMAL(18,6))
                END
            ELSE NULL
        END AS plan_post_assist,
        -- cum_plan_qty: 累计计划销量
        -- 1~180天: 滚动累计(不含当天N)
        -- 超周期段: 保持第180天值(不带 ORDER BY 的聚合窗口函数,整个分区求和)
        CASE WHEN pc.lifecycle_day BETWEEN 1 AND 180 THEN
            SUM(CASE WHEN pc.lifecycle_day BETWEEN 1 AND 180
                     THEN pc.plan_post_final ELSE 0 END
               ) OVER (PARTITION BY pc.style_no ORDER BY pc.sale_date
                       ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)
        ELSE
            SUM(CASE WHEN pc.lifecycle_day BETWEEN 1 AND 180
                     THEN pc.plan_post_final ELSE 0 END
               ) OVER (PARTITION BY pc.style_no)
        END AS cum_plan_qty
    FROM plan_calc_skc pc
),
-- ============================================================
-- 6.6 ★计算 cum_plan_post_assist = 截至N-1天的 SUM(plan_post_assist)
--     逻辑同 cum_plan_qty,只是把 plan_post_final 换成 plan_post_assist
-- ============================================================
plan_with_cum_assist_skc AS (
    SELECT
        pa.*,
        CASE WHEN pa.lifecycle_day BETWEEN 1 AND 180 THEN
            SUM(CASE WHEN pa.lifecycle_day BETWEEN 1 AND 180
                     THEN pa.plan_post_assist ELSE 0 END
               ) OVER (PARTITION BY pa.style_no ORDER BY pa.sale_date
                       ROWS BETWEEN UNBOUNDED PRECEDING AND 1 PRECEDING)
        ELSE
            SUM(CASE WHEN pa.lifecycle_day BETWEEN 1 AND 180
                     THEN pa.plan_post_assist ELSE 0 END
               ) OVER (PARTITION BY pa.style_no)
        END AS cum_plan_post_assist
    FROM plan_with_assist_skc pa
)
SELECT
    sc.style_no                                            AS style_no,
    sc.sale_date                                           AS sale_date,
    sc.lifecycle_day                                       AS lifecycle_day,
    -- 口径6.1节：sale_date_label
    CASE WHEN sc.lifecycle_day BETWEEN 1 AND 180
         THEN CAST(sc.lifecycle_day AS VARCHAR)
         ELSE '超周期'
    END                                                    AS sale_date_label,
    -- 口径6.2节：销售周期标签
    CASE
        WHEN sc.lifecycle_day BETWEEN 1 AND 30    THEN '新品期'
        WHEN sc.lifecycle_day BETWEEN 31 AND 120  THEN '热销期'
        WHEN sc.lifecycle_day BETWEEN 121 AND 180 THEN '清货期'
        ELSE '超周期'
    END                                                    AS sales_cycle_label,
    -- 口径6.2节：ratio
    sc.ratio                                               AS ratio,
    -- 三期口径第2节：SKC销售计划标签
    sc.sales_plan_tag                                      AS sales_plan_tag,
    sc.brand                                               AS brand,
    sc.shelf_date                                          AS shelf_date,
    sc.order_qty                                           AS order_qty,
    -- 三期口径第4节：plan_pre
    sc.plan_pre_final                                      AS plan_pre,
    -- 三期口径第4节：plan_post
    sc.plan_post_final                                     AS plan_post,
    -- 三期口径第3节：plan_post_assist
    sc.plan_post_assist                                    AS plan_post_assist,
    -- 口径6.5节：实际销售
    sc.actual_qty                                          AS actual_qty,
    sc.actual_amt                                          AS actual_amt,
    -- 累计实际销量 = 截至N-1天的 SUM(qty)
    COALESCE(sc.cum_actual, 0)                             AS cum_actual,
    COALESCE(sc.cum_actual_amt, 0)                         AS cum_actual_amt,
    -- SKC累计计划销量 = 截至N-1天的 SUM(plan_post_final)
    sc.cum_plan_qty                                        AS cum_plan_qty,
    -- SKC累计 plan_post_assist = 截至N-1天的 SUM(plan_post_assist)
    sc.cum_plan_post_assist                                AS cum_plan_post_assist,
    -- SKC累计计划金额 = 占位0（后续补全）
    CAST(0 AS DECIMAL(18,6))                               AS cum_plan_amt,
    -- SKC应达成比例 = cum_plan_qty / order_qty
    CAST(sc.cum_plan_qty AS DECIMAL(18,6))
        / NULLIF(CAST(sc.order_qty AS DECIMAL(18,6)), 0) AS should_achieve_ratio,
    -- 口径6.6节：达成情况 = actual_qty / plan_post
    CASE WHEN sc.lifecycle_day BETWEEN 1 AND 180
         THEN CAST(sc.actual_qty AS DECIMAL(18,6))
              / NULLIF(sc.plan_post_final, 0)
         ELSE NULL
    END                                                    AS achievement_rate,
    sc.inventory_sku                                       AS inventory_sku,
    sc.available_inventory                                 AS available_inventory,
    -- 口径5.11节：可售周期 = SKC在仓库存 / 30天平均日销
    CASE
        WHEN sc.inventory_sku = 0 THEN NULL
        WHEN sc.lifecycle_day BETWEEN 1 AND 180 THEN
            CASE
                WHEN COALESCE(sc.rolling_30d_qty, 0) = 0 THEN NULL
                WHEN LEAST(sc.lifecycle_day - 1, 30) = 0 THEN NULL
                ELSE CAST(sc.inventory_sku AS DECIMAL(18,6))
                     / (CAST(sc.rolling_30d_qty AS DECIMAL(18,6))
                        / LEAST(sc.lifecycle_day - 1, 30))
            END
        ELSE
            COALESCE(c30.current_sellable_days, 0)
    END                                                    AS sellable_days,
    sc.sync_time                                           AS sync_time,
    CURRENT_TIMESTAMP()                                    AS insert_date,
    CURRENT_TIMESTAMP()                                    AS update_date
FROM plan_with_cum_assist_skc sc
LEFT JOIN current_30d_avg_skc c30 ON sc.style_no = c30.style_no
ORDER BY sc.style_no, sc.sale_date;
```

## 附：关键改动对比

| 项目 | 原递归版本 | 闭式解版本 |
|---|---|---|
| CTE 结构 | WITH RECURSIVE + base + step + UNION ALL | WITH + closed_form_base + P + S + plan_calc |
| 核心算法 | 逐天递推 cum_is_not_0_sum(N) = prev.cum + CASE(prev.actual=0) | 闭式解 R(N) = P(N) * (Q - S(N)) |
| 累计运算 | 递归依赖 prev 行 | 窗口函数 EXP(SUM(LN(k))) + SUM(d/P_i1) |
| 情况1/2 1~180天 | 递归计算 cum_is_not_0_sum 后代入公式 | 直接用 R(N) * ratio / (181-N) |
| 情况3 1~180天 | 递归框架内统一处理（但本不依赖递归） | 直接用 (Q-cum_actual)*ratio/(181-N) |
| 超周期段 | 递归框架内特判 | CASE WHEN lifecycle_day>180 特判 |
| 性能 | 极慢（180段UNION ALL 展开后卡死） | 单趟扫描，窗口函数原生支持 |
| SQL 行数 | 600+ 行（含递归展开） | ~400 行（无展开） |
| StarRocks 兼容 | 需手动展开（不支持 RECURSIVE） | 原生支持 |

## 数学等价性

闭式解与原递归公式在数学上完全等价（详见《闭式解方案-非递归实现plan_post_assist.md》第五、六、七章的验算）：

- 情况1示例（Q=1000，全无实际销量）：plan_post 数值与口径文档完全一致
- 情况2示例（Q=1000，第1/2天有实际销量）：plan_post 数值与口径文档完全一致
- 交叉验证：闭式解 R(N) = 原公式 (Q - cum_actual - cum_is_not_0_sum) 数值完全一致
