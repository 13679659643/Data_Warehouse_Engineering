## 4.5 从加减法递推到最终闭式解的推导

这一步的核心逻辑非常直白，关键在于**不要忘了我们最初是怎么定义中间变量 T(N) 的**。

以下是完整的推导过程拆解：

### 1. 展开求和，找出 T(N) 的通项

我们上一步得出了加减法递推公式：

```
T(N+1) = T(N) - d(N) / P(N+1)
```

这个公式的意思是：**后一项 = 前一项 减去 一个常数**。

既然是这种简单的加减法，我们完全可以把它一层层展开写出来：

- 第 2 项：`T(2) = T(1) - d(1) / P(2)`
- 第 3 项：`T(3) = T(2) - d(2) / P(3) = T(1) - d(1) / P(2) - d(2) / P(3)`
- 第 4 项：`T(4) = T(3) - d(3) / P(4) = T(1) - d(1) / P(2) - d(2) / P(3) - d(3) / P(4)`
- ......
- 一直推导到第 N 项：

```
T(N) = T(1) - ( d(1) / P(2) + d(2) / P(3) + ... + d(N-1) / P(N) )
```

为了简化书写，我们把括号里这一长串求和，用一个新符号 S(N) 来代替：

```
S(N) = Σ(i=1 到 N-1) [ d(i) / P(i+1) ]
```

所以，T(N) 的通项公式就变成了：

```
T(N) = T(1) - S(N)
```

### 2. 计算初始值 T(1)

上面式子里的 T(1) 是多少呢？

我们回到最开始的定义。在推导的第一步，我们令 `T(N) = R(N) / P(N)`。

当 N=1 时：

```
T(1) = R(1) / P(1)
```

根据业务已知条件：

- 第一天的剩余量等于全部订货量，即 `R(1) = Q`
- 累积乘积的初始值规定为 1（空乘积），即 `P(1) = 1`

所以：

```
T(1) = Q / 1 = Q
```

把 `T(1) = Q` 代回第 1 步的通项公式，就得到了：

```
T(N) = Q - S(N)
```

### 3. 回代：把 T(N) 变回 R(N)

现在我们已经求出了 T(N) 的值。但是，T(N) 只是我们为了方便计算而凭空捏造出来的一个"中间替身"，我们真正要求的其实是 R(N)。

怎么办？**再变回去就好了**。

因为我们一开始的定义是：

```
T(N) = R(N) / P(N)
```

把这个式子稍微变形一下，把 R(N) 提取出来：

```
R(N) = P(N) × T(N)
```

最后，把刚才求出的 `T(N) = Q - S(N)` 塞进这个式子里，替换掉 T(N)：

```
R(N) = P(N) × [Q - S(N)]
```

这就是最终的闭式解！

### 总结

这一步的逻辑就是：我先找个替身 T(N) 把复杂的公式算完（得出 `T(N) = Q - S(N)`），算完之后，再把真身 R(N) 换回来（通过 `R(N) = P(N) × T(N)`）。
