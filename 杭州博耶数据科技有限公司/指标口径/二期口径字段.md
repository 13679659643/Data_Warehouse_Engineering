# 二期口径字段

## SKU字段口径定义

### 1 商品名称

| 项       | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 数据来源 | `feishu_ads.ads_sku_sales_plan_180d_d.product_name`    |
| 口径     | QuickBI可视化层,直接查询ADS表，AS别名使用ADS字段备注名称 |

### 2 计划金额

| 项       | 说明                                                                                                                                                                                                                                                               |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 数据来源 | 吊牌价：`feishu_dws.dws_sku_product_info_d.tag_price`，计划销量：`feishu_dws.dws_sku_sales_plan_180d_d.plan_post`                                                                                                                                              |
| 口径     | tag_price吊牌价使用逻辑，如果ip不等于服配和篮球，参考《ip不等于服配和篮球，吊牌价和销售美金的对应关系》，得到销售美金的值，固定乘以6.8，就是最终预计收款单价，预计收款单价*计划销量就是计划金额；如果ip等于服配或篮球，计划金额=tag_price*1.2*计划销量           |
| 具体实施 | 插入 `feishu_ads.ads_sku_sales_plan_180d_d`表的时候，feishu_dws.dws_sku_sales_plan_180d_d通过style_no_size关联feishu_dws.dws_sku_product_info_d，根据ip判断tag_price是否需要转化为对应销售美金乘以6.8或者直接乘以1.2 ，然后后在乘以计划销量plan_post得到计划金额 |

> **ip不等于服配和篮球，吊牌价和销售美金的对应关系**：
> 199吊牌价对应销售美金59
> 299吊牌价对应销售美金59
> 599吊牌价对应销售美金99
> 699吊牌价对应销售美金119
> 899吊牌价对应销售美金149
> 999吊牌价对应销售美金159
> 1199吊牌价对应销售美金199
> 1399吊牌价对应销售美金225

| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据来源 | 吊牌价：`feishu_dws.dws_sku_product_info_d.tag_price`，累计计划销量：`feishu_dws.dws_sku_sales_plan_180d_d.cum_plan_qty`                                                                                                                                                  |
| 口径     | tag_price吊牌价使用逻辑，如果ip不等于服配和篮球，参考《ip不等于服配和篮球，吊牌价和销售美金的对应关系》，得到销售美金的值，固定乘以6.8，就是最终预计收款单价，预计收款单价*累计计划销量就是累计计划金额；如果ip等于服配或篮球，累计计划金额=tag_price*1.2*累计计划销量      |

### 4 已销售天数

| 项       | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 数据来源 | `feishu_dws.dws_sku_sales_plan_180d_d.lifecycle_day`    |
| 口径     | 插入ADS层的feishu_ads.ads_sku_sales_plan_180d_d时候，新增current_lifecycle_day字段，始终为当前时间的lifecycle_day，即已销售天数；current_lifecycle_day是针对SKU维度、当前时间的一个常量 |

### 5 可售周期-基于订货数量

| 项       | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 数据来源 | 订货数量：`feishu_dws.dws_sku_product_info_d.order_qty` 、 SKC 30天平均日销(核心4渠道)：`feishu_dws.dws_sku_sales_plan_180d_d.daily_avg_qty_30d`、累计实际销量(截至N-1天)：`feishu_dws.dws_sku_sales_plan_180d_d.cum_actual` |
| 口径     | 插入feishu_dws.dws_sku_product_info_d时候，有order_qty、daily_avg_qty_30d、cum_actual字段或者计算逻辑，可售周期-基于订货数量 = （订货数量 - 累计实际销量(截至N-1天)）/ SKC 30天平均日销(核心4渠道)，始终是针对SKU维度、当前时间的一个常量，每天刷新。 |

### 6 订货比例

| 项       | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 数据来源 | `feishu_dws.dws_sku_product_info_d.order_qty`    |
| 口径     | 插入feishu_dws.dws_sku_product_info_d.order_qty时候，新增order_qty_ratio字段，逻辑为单个style_no_size(即SKU维度)的order_qty_ratio = order_qty(单个style_no_size) / SUM(order_qty) by style_no ，比如，一个style_no下有三个style_no_size的order_qty分别是100、200、300，那么这三个SKU的order_qty_ratio = 100 / (100+200+300) = 0.25、200 / (100+200+300) = 0.5、300 / (100+200+300) = 0.75 |

### 7 销售比例

| 项       | 说明                                                     |
| -------- | -------------------------------------------------------- |
| 数据来源 | 累计实际销量(截至N-1天的SUM(qty))：`feishu_dws.dws_sku_sales_plan_180d_d.cum_actual`,只需要取sale_date为当前时间的cum_actual，就得到了当前时间的累计实际销量(截至N-1天的SUM(qty))    |
| 口径     | 插入ADS层的feishu_ads.ads_sku_sales_plan_180d_d时候，新增sales_qty_ratio字段，逻辑为单个style_no_size(即SKU维度)的sales_qty_ratio = cum_actual(单个style_no_size) / SUM(cum_actual) by style_no ，比如，一个style_no下有三个style_no_size的cum_actual分别是100、200、300，那么这三个SKU的sales_qty_ratio = 100 / (100+200+300) = 0.25、200 / (100+200+300) = 0.5、300 / (100+200+300) = 0.75 ，始终是针对SKU维度、当前时间的一个常量，每天刷新。`feishu_dws.dws_sku_sales_plan_180d_d`表维度是`style_no_size`, `sale_date`，所以销售比例sales_qty_ratio字段针对同一个`style_no_size`的不同的`sale_date`，值是一样的。|
